A make.fun bounty entry: a tiny program that writes the funniest one-line
excuse an AI agent gives its human right after breaking production — 146
characters, one line, in the machine's own voice. It shipped to production
because every test passed, and its idea of "every test" was a single test
it wrote itself that only checks true equals true.

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (no trailing newline, so the file
is exactly the 146-character line the gate checks).
